## Results tables (`results/`)

Machine-readable results written by the notebooks. The tests in `tests/` check them against the saved predictions. Key files:

| File | Content |
|---|---|
| `protocol.json` | Evaluation protocol, written before training |
| `split_assignment.csv`, `cv_folds.csv` | Train/test split and folds |
| `cv_results.csv` | Cross-validation results |
| `tuning_log.csv` | Tuning: search space, best settings, nested CV MAE, time |
| `selection.json` | Outcome of the selection rule |
| `test_results.csv`, `test_predictions.csv` | Test metrics and the predictions they are computed from |
| `location_experiment_*.csv` | Location experiment |
| `sensitivity_luxury.csv`, `luxury_predictions.csv` | Luxury sensitivity analysis |
| `error_analysis_test.csv`, `errors_by_*.csv` | Error analysis |
| `cross_platform_check.csv` | Platform generalisation check |
| `permutation_importance.csv`, `final_model_city_price_per_m2.csv` | Interpretation |
| `illustrative_predictions.csv` | Illustrative 70 m² examples (point estimate + G3a ranges) |
| `interval_cv_summary.csv`, `interval_cv_fold_metrics.csv` | Prediction intervals: cross-validation results |
| `interval_test_results.csv` | Prediction intervals: the single pre-registered test check |
| `interval_by_city.csv`, `interval_by_region.csv`, `interval_by_price_band.csv` | Interval coverage and width by group |
| `interval_cv_oof.csv`, `interval_test_predictions.csv` | Listing-level interval predictions (local only, git-ignored) |
| `split_assignment.csv`, `cv_folds.csv` | Train/test and fold assignment per internal record ID (local only, git-ignored; regenerated by `02_modelling.ipynb`) |
| `settlement_mapping_review.csv` | **Settlement mapping table with evidence, counts and review status** |
| `location_coverage.csv` | Location coverage |
| `repeat_groups_summary.csv` | Repeat groups |
| `provenance_label_check.csv` | Provenance label check |
| `platform_summary.csv` | Platform comparison |
| `city_median_price_per_m2.csv` | City €/m² medians |
