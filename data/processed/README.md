# Generated data

Files here are generated by `notebooks/01_eda.ipynb`. Do not edit them by hand; re-run the EDA notebook instead. Re-running produces byte-identical files; this is checked by `tests/test_data.py::test_export_is_reproducible` and by the slow reproducibility test.

| Output file | Content |
|---|---|
| `valora_apartments_clean.csv` | **The modelling dataset**: 1,380 real apartment sale listings (1,376 `primary` + 4 `extended only`). Loaded by `02_modelling.ipynb`. |
| `cleaning_flow.csv` | Every cleaning step: rows before, rows after, rows affected, reason. 6,913 → 1,376. |
| `exclusion_summary.csv` | Excluded real listings by type of problem (data error, rental, misclassified type, invalid value, duplicate, valid-but-extreme). |
| `exclusion_log.csv` | One row per real listing not in the primary population: `record_id`, platform, reason, price, area. No URLs or text. |

There are no timestamps: the source has no listing dates.

## `valora_apartments_clean.csv`

| Column | Meaning | Units / values |
|---|---|---|
| `record_id` | Internal ID, stable while the raw file is unchanged | `VAL-0001` … `VAL-1986` |
| `platform` | Platform of the advert (audit and error analysis only, **not** a model input) | Realitica, Realitica Adriatic, Estitor |
| `population` | `primary` = main analysis; `extended only` = valid listing outside the earlier ranges (price > €2M or area > 350 m²) | category |
| `price_eur` | **Target**: advertised asking price | EUR |
| `area_m2` | Living area | m² |
| `rooms` | Rooms as advertised; studio = 0; empty = not stated | count |
| `is_studio` | Studio (*garsonjera*) | True / False |
| `price_per_m2` | price ÷ area (EDA only; **never** a model input) | EUR/m² |
| `city_original` | Platform `city` field, if it is a municipality | 25 municipalities or `Unknown` |
| `city_explicit`, `city_explicit_method` | City from the location text without settlement mapping, and how it was found | municipality / `Unknown`; method |
| `city_clean`, `city_method` | **Main city version**: explicit location + 15 reviewed settlement mappings | municipality / `Unknown`; Original valid city, Explicit location match, Reviewed settlement mapping, Ambiguous, Conflict, Unknown |
| `neighbourhood` | First part of the location text | text (place name) |
| `repeat_group` | Probable same flat (same city, neighbourhood, price, area); used to keep groups together in splits | `G0001` … |
| `repeat_group_size` | Listings in the group | count |
| `repeat_cross_platform` | Group spans two platforms | True / False |
| `repeat_rooms_conflict` | Room counts disagree inside the group (possible wrong link) | True / False |
| `source_check_flag` | Author's manual check column simplified | `OK` / `check` |

**How modelling loads it:** `pd.read_csv('data/processed/valora_apartments_clean.csv')`, then `population == 'primary'` for the main analysis.
